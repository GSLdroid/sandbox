# Giant Steps Sandbox

A throwaway practice website for demonstrating AI agent web editing to students and workshop audiences.

## How it works

1. Someone tells an AI agent, in plain English, what to change ("add a button", "make the header orange", "add a section about dogs").
2. The agent edits `index.html` in this repo and pushes the change.
3. GitHub Pages republishes the site, usually within a minute or two. Refresh to see the change.

## Notes

- Everything lives in a single `index.html` file so changes are easy to see and undo.
- Nothing here is connected to any other site. Break it freely.
- To reset, restore `index.html` from the first commit.
